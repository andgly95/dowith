# Do With: Just us, reimagined

The design handoff for a new take on "Just us", the pleasure inventory behind the rose in a
pair list: a front door that is safe to glance at, a body map with Together / Yours / theirs
views, a deck of cards for things to try, and a page for what you both want.

- **Start with [HANDOFF.md](HANDOFF.md).** It is written for the Claude Code session that
  builds this, assumes `CLAUDE.md` and `design/redesign/HANDOFF.md` have been read, and ends
  with a build order. It is a client-only change: the server and its privacy rules stay as
  they are.
- **See it:** open [index.html](index.html) in a browser for every screen, with a
  Dusk / Forest toggle.
- **Source:** `mockup-src/` holds the design canvas's artboards. `screens/` is generated from
  them by `mockup-src/render.mjs`.

The partner in every mockup is a stand-in called Sam, and every answer is made up. No
screenshots of the live feature are in this public repo.
