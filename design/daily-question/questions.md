# Today's question: a starter catalogue

Three kinds. Most questions are **open** (a sentence back). Some are **this or that**
(`pick`), two options, which make for a quick day and the nicest kind of match: "You both
said a mountain cabin". Ids are stable once shipped: a shipped id is never reused for
different words, because past days store the id.

The bar for a question: answerable in a sentence, about the two of you or about the person
answering, and something the other would actually want to read. Questions that lead to a
thing to do ("what should we do this weekend?") are worth a lot here, because **Add to
Activities** turns the answer into an item on the list.

This is a starting set to ship with, not the last word. Add to it freely.
