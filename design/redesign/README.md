# Do With redesign

The design handoff for the Do With refresh and the new Places experience.

- **Start with [HANDOFF.md](HANDOFF.md).** It is written for the Claude Code session that
  builds this, assumes `CLAUDE.md` has been read, and ends with a build order.
- **See it:** open [index.html](index.html) in a browser for every screen, with a
  Dusk / Forest toggle.
- **Source:** `mockup-src/` holds the design canvas's artboards. `screens/` is generated from
  them by `mockup-src/render.mjs`.

The live, interactive version (ticking, adding, the To go / Been switch, "We went here")
is Andrew's private design canvas: <https://claude.ai/artifact/R4Kht1AKJgUJVnMKCusQvg>.
The "before" screenshots are only on the canvas, not in this public repo.
