# Do With: cooking, rethought

The design handoff for a new Recipes experience: reading a recipe from its link,
servings that rescale, a pantry for each of you, a shopping list, cook mode with timers,
and a record of what you made.

- **Start with [HANDOFF.md](HANDOFF.md).** It is written for the Claude Code session that
  builds this, assumes `CLAUDE.md` and `design/redesign/HANDOFF.md` have been read, and
  ends with a build order.
- **See it:** open [index.html](index.html) in a browser for every screen, with a
  Dusk / Forest toggle.
- **Source:** `mockup-src/` holds the design canvas's artboards. `screens/` is generated from
  them by `mockup-src/render.mjs`.

The live, interactive version (servings, ticking ingredients, running timers, the Mine /
Linnea's switch) is Andrew's private design canvas:
<https://claude.ai/artifact/R4Kht1AKJgUJVnMKCusQvg>. The "before" screenshots are only on
the canvas, not in this public repo. The recipe text in the mockups was written for them
and is not NYT's.
